# 실행 종료와 시간 예산

LLM이 자료를 확보했더라도 최종 응답을 내지 못하면 완료가 아니다. DustAgent는 최종 결과, 모델 턴 기록, 실제 도구 응답을 분리해서 반환한다.

```sh
dust run crawler --json --max-turns 15 --timeout-ms 120000 --tool-timeout-ms 15000 "URL"
dust run crawler --report reports/crawl.json "URL"
```

## 결과 계약

ExecutionReport는 stop_reason, output, turns_used, elapsed_ms, turns, tool_calls, validation, error, warnings를 담는다. 종료 사유는 completed, turn_limit, time_limit, tool_timeout, empty_response, execution_error, validation_failed다. completed는 비어 있지 않은 최종 응답을 받았고 설정된 검사기가 있다면 통과했다는 뜻이다. 실제 작업 전체를 끝냈다거나 모든 링크를 관찰했다는 뜻은 아니다.

각 모델 턴은 응답 내용과 요청한 도구 개수, 소요 시간, 오류를 기록한다. 각 도구 호출은 이름, 인자, 성공/실패/시간초과/인자오류, 실제 응답, 소요 시간과 잘림 여부를 기록한다. 도구 응답에 발견 290 / 관찰 100 / 남은 190 같은 메타데이터가 있으면 그대로 남긴다. 코어가 없는 범위 정보를 만들어 내지는 않는다.

턴·시간 소진 후 output에 마지막 중간 응답이 남을 수 있다. 이것을 최종 결과로 사용하지 않도록 기본 raw 출력은 완료 시에만 STDOUT으로 내보낸다. --json은 실패 보고서도 출력한다. 실패 여부는 종료 코드로 함께 판단한다.

종료 코드: 완료 0, CLI 입력·설정·파일 오류 1, 턴 소진 2, 전체/도구 시간 소진 3, 모델 빈 응답 4, 실행 오류 5, 결과 검사 실패 6. 도구 오류 후 모델이 복구해서 응답할 수는 있지만 오류 기록은 지워지지 않는다. 오류가 있는 실행은 성공 사례로 승격할 수 없다.

## 시간과 종료 관리

기본 전체 예산은 300000ms, 도구 호출당 30000ms, 모델 턴 수는 10이다. 매니페스트 timeout_ms, tool_timeout_ms, max_turns로 설정하고 CLI 옵션으로 덮어쓴다. 시간 값은 1~86400000ms다.

CLI의 전체 예산은 MCP 시작과 경험 검토부터 모델/도구 호출까지 연결된다. 라이브러리 execute_report는 도구 목록 조회와 모델/도구 실행을 포함하며 init_scoped_mcp는 별도로 제한한다. 동기 입력·저장소 읽기·보고서 쓰기에는 강제 중단을 적용하지 않는다.

도구 시간초과는 실행을 즉시 중단한다. 취소한 stdio 요청의 늦은 응답이 다음 요청에 섞이지 않도록 해당 클라이언트를 제거한다. 외부 서버에서 작업이 이미 수행됐는지는 알 수 없으며 자동 재시도하지 않는다. 취소 후 클라이언트 정리에 최대 1초, 전체 shutdown에는 별도 최대 5초를 허용한다. 정리 오류는 보고서 warnings에 남긴다.

## 결과 검사와 기록 제한

validation이 선언돼 있으면 최종 응답을 실제 검사기에 전달한다. 기본 legacy 모드는 통과하지 못하면 validation_failed로 종료한다. feedback 모드에서는 complete/continue/blocked 판정을 받아 continue이면 근거를 모델에 돌려주고 같은 예산 안에서 실행을 이어간다. 원본 응답과 검사 이력을 보고서에 남긴다. 검사 자체도 전체 예산 안에서 수행한다. 경험 저장소에는 검사 근거를 함께 기록하며, 실패/미완료 실행은 성공 사례가 되지 않는다.

도구 응답 기록은 호출당 최대 64 KiB, 모델 중간 응답 기록은 턴당 최대 4 KiB, 두 기록의 문자열 합계는 최대 1 MiB다. 잘림 여부를 표시하며 도구 결과가 잘리면 모델에도 더 좁은 결과를 요청하라는 피드백을 보낸다. 최종/부분 output와 도구 인자는 별도로 남기며 이 문자열 제한에 포함하지 않는다. 따라서 전체 JSON 파일 크기를 1 MiB로 보장하지 않는다.

--report는 종료 시 JSON 파일을 임시 파일에 쓴 뒤 원자적으로 교체한다. Unix 파일 권한은 0600이다. 보고서에는 입력 인자와 실제 도구 출력 같은 민감한 내용도 포함될 수 있다.

종료 보고서는 실행 중 저장하는 체크포인트와 별개다. 프로세스 재시작 후 이어가는 방법과 재개를 차단하는 조건은 [[13_체크포인트_및_재개]]를 참고한다. 브라우저 세션은 복원하지 않는다.

실행 루프의 일시적인 모델 요청 실패는 제한된 재시도로 복구한다. 검사 피드백·재시도 기록·작업 메모의 세부 계약은 [[15_완료_피드백_및_실행_복구]]를 참고한다.
